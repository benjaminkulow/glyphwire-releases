# Glyphwire – Downloads

Hier liegen die fertigen Programme von **Glyphwire** für die automatische Aktualisierung und zum Herunterladen. Der Quellcode liegt in einem eigenen Repository.

- **Download:** unter **Releases** das neueste `Glyphwire-<Version>-windows-amd64.zip` laden, entpacken und `Glyphwire.exe` starten.
- **Prüfen:** Jedes Release enthält `SHA256SUMS.txt`. Die Datei `latest.json` ist mit einem Ed25519-Schlüssel signiert (`latest.json.sig`); Glyphwire prüft die Signatur vor jedem Update.

Dieses Repository wird ausschließlich vom Release-Workflow beschrieben.
